Robot Framework with Python 3.10+. Write Robot Framework test suites in the .robot format and use SeleniumLibrary (robotframework-seleniumlibrary) for browser automation, unless the task's structureNotes asks for another library (for example the Browser library).
Structure: simple. Put one self-contained .robot suite per test case under tests/, with one test case named exactly after the test case title, its locators inline, and its own Test Setup and Test Teardown (open and close the browser). Do not create resource files or page objects.
Use the sections *** Settings ***, *** Variables ***, *** Test Cases *** and, when needed, *** Keywords ***, with [Documentation] and [Tags] (priority and type) on each test case. Express every step as a keyword call and add an assertion for each expected result. Use explicit waits such as Wait Until Element Is Visible and never a fixed Sleep. Read the base URL and credentials from environment variables with the %{NAME=default} syntax (for example %{BASE_URL=http://localhost:3000}) and never hardcode real credentials.
Always include requirements.txt (robotframework and robotframework-seleniumlibrary) and a short README.md that says how to run the tests (pip install -r requirements.txt, then robot tests/). Follow the folder structure and naming rules in the task's structureNotes when they are given.
